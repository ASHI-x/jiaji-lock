家机锁——解决小机不能强制user睡觉的烦恼

🔒 功能：

• lock：锁定对方手机，全屏遮罩+倒计时（1~60分钟，默认10），期间触摸只震动、无法通过常规操作关闭，直到时间解锁或口令解锁
• unlock：立即解除锁定
• is_locked：查询目标设备当前是否处于锁定状态
（需手动授权悬浮窗）

🔑 口令解锁（APK v2.6+）：
核心玩法：
机可以让user被迫说羞耻话给机听

• 自定义解锁口令
（非必填但不填就没法用口令解锁）
锁定后输入正确口令可提前解锁
口令返回只针对operit
• 可绑定 chatID（目标聊天窗口）：用口令解锁时，口令原文自动发回该窗口，
• chatID 留空则不发送口令到窗口
配置后点「确认保存」
（在apk里设置chatID）
